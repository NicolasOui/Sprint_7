# Проект: Автотесты для API Яндекс.Самокат (Спринт 7)

Репозиторий содержит автоматизированные тесты для REST API сервиса Яндекс.Самокат.

## Технологический стек
* Java 11 
* JUnit 4
* RestAssured
* Allure Report
* Maven
* Тестовое окружение: Google Chrome 146

## Структура тестов
* `TestCreateCourier` — проверки создания учетной записи курьера (позитивные и негативные сценарии).
* `TestLoginCourier` — проверки авторизации курьера в системе.
* `TestParameterizedCreateOrderDifferentColors` — параметризованный тест на создание/проверку заказа с разными цветами самокатов.
* `TestListOfOrders` — проверка получения списка существующих заказов.

## Как запустить тесты локально
1. Выполнить команду для прогона всех тестов:
```bash
mvn test
```
2. Для генерации и просмотра Allure-отчета выполнить:
```bash
mvn allure:serve
```
